# Contributing to TikTok-Now

Thank you for considering contributing to **TikTok-Now**!

## Development Guidelines

1. **Rust & Tauri v2**: Follow standard Rust code styling (`cargo fmt`) and check for warnings (`cargo check`).
2. **Frontend Injections**: Keep JS injections modular and lightweight to maintain low memory usage and fast render times.
3. **Commit Messages**: Use clear and descriptive commit messages summarizing the feature or bug fix.
